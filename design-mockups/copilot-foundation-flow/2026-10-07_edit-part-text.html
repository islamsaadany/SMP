Edit a part's text yourself

Today a part's draft can only be changed by asking the Copilot or pressing a refine button. The proposal turns the draft into a box you can type into. Everything else on the screen stays where it is. These shots are taken from the real platform with Mobile's Who We Are draft.

How it behaves

  • What you type is kept as the draft when you leave the box, the way every other box in the platform saves. There is no separate Save for the text.
  • Save and continue uses whatever is in the box. The refine buttons rewrite starting from what you typed, not from the older version.
  • The same box appears whenever a part's draft is open: while drafting, when you press a finished part on the left, and when you open a part from the consistency check.
  • A part that was Done stays Done after you edit its text. If the consistency check had already run, it shows as needing to run again, because the text it checked has changed.
  • Once the Foundation is saved as a deliverable, the box goes back to read-only, as everything in a saved flow is today.

Two things to confirm

  1. The box as drawn: white, bordered, gold outline while typing, growing with the text.
  2. Editing a finished part keeps it Done, and asks for the consistency check again if it had already run. The other way would be to mark the part as needing a fresh "Save and continue".
