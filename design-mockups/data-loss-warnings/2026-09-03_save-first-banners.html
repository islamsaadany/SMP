SMP · Save-safety banners · §258.2 · 3 September 2026

Reload saves first, and the banner says so

Every picture below is the real built platform, shot from the branch, not a drawing. Both buttons now commit the box you are in, save, and reload only when the server has answered “saved”.

  • The instruction you asked for — “Finish what you are typing, then press Reload” — on both banners.
  • The page is named in the second banner, and the banner leaves when you move to another tab.
  • A failed save never reloads — the red bar explains, the amber one stays, the button comes back.

Names the person AND the page. Goes away by itself when you move to another tab.

While it saves

Either button reads Saving… until the server answers. The reload happens only on the word “saved”.

If the save fails

Nothing reloads. The red bar says why, the amber one stays, and the button is live again.
