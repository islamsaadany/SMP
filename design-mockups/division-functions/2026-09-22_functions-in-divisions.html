Functions that belong to a division

Drawn from the running platform, using Raya Trade's own Distribution and B2C. Which functions sit where, and every weight, are examples — nothing here is decided until you set it on Setup.

What you agreed

The rules this draws

  • Divisions are the existing companies. The word can be renamed to “Division” on Terminology if you prefer.
  • A supporting function belongs to the group (as today) or to exactly one division.
  • It counts in that division's score, with a weight set on Setup.
  • The division's CEO can see its functions but not report on them.
1 · The division's Performance page

What moves: the headline cards read Performance and Execution instead of “Business units — …”, because they now include the functions. A Supporting functions section sits under the units, using the same card. Share of the group doesn't change: functions have no group weight, so it still counts units only.

The functions take their share first (20% + 20% = 40%). The units split the remaining 60% in proportion to the weights they already carry at group level, so their order and relative sizes never change.

How a function's weight works

Three kinds of division

Units and functions, some weights setDistribution above: a blank weight takes the average of the ones that are set. Nothing ever counts as zero because a box was left empty.
Units and functions, no weights setB2C: 3 units + Marketing + Care. Each function counts as one equal member, 1 of 5 = 20%. The units share the other 60% by their group weights.
Functions onlyA division holding no units scores on its functions alone: set weights are used as given, blanks take the average, and with none set they count equally.

A division that holds no functions scores exactly as it does today. If the functions' weights add up to more than 100%, the setting is refused and says why. Changing a function to another division, or back to the group, moves its score with it.

2 · Where it is set — Setup › Functions

Two new columns, Company and Weight (the gold shading only marks what's new in this drawing). Both are set in the row's existing Edit details dialog, like the other fields. A function at group level shows “The group” and no weight. Note: Merchandising's existing Under Retail Stores means “borrows Retail Stores' aspiration and SWOT”. That's a different thing from belonging to a division, and it stays as it is.

What does not change
  • The group's own scores and pages. Functions still don't count toward the group score.
  • Any function you leave at group level.
  • Who can report on a function: its head and custodian, as today. The division's CEO can see it but not report.
