Terminology: one word for each thing, used everywhere

Setup › Terminology, drawn in the running platform. Each row says what the thing is, the platform's default word, and your word. The words in the boxes are examples of what a client might type (Vision, Divisions).

What changes

  • No term name column. Each row opens with a plain description of the thing, so nobody has to know our internal names.
  • One word per thing, on every page. The separate group and business-unit columns go. Whatever you type shows at the group, in every business unit and in every function.
  • The default sits beside the box, so you can always see what the platform would say. Reset appears only when your word differs from the default. Emptying the box does the same thing.
  • A new row for companies (shaded here only to mark it as new). Its default is Companies; a client like yours would type Divisions.

What this changes on today's screens

  • The aspiration now uses one word. Today the group page says Vision and a business unit says Winning Aspiration. Its default becomes Winning Aspiration everywhere; a client who wants Vision types it once.
  • The group's capabilities get their own row. Today they are listed as the Pillars row's group-level word ("Group capabilities"), but they are a different thing from a unit's pillars. Their default is Capabilities, the word the navigation already uses.
  • Where a client has already typed two different words for one row, the word shown on business-unit pages is kept. Mission and Core Values have only ever had one word, so nothing changes for them.
