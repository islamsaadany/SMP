What is actually empty

The Collabs. column — tactics with nobody supporting them. On Mobile that is 22 of 22 tactics; on Care CA01 both tactics show a dash.

You ruled that a tactic with no collaborators is not missing — a tactic one person owns is a complete line. So the red count, the pillar badges and the next-gap walk, which all read the missing list, correctly show nothing. A separate rule says an empty collaborators box is still something a filler may write in, and that rule is what draws the button. Both are working. Nobody joins them up.

The rules this follows

  • QuietGrey, never red and never amber. Red means missing and amber means pending — an empty collaborators list is a fact on a healthy plan, not a warning.
  • The word“empty”, never “missing”. The bar already said it; the count and the chips say it too.
  • CountsNothing changes about scores, averages, what Submit refuses, the deck's red Missing, or the workbook. This is a way of finding boxes, not a new obligation.
  • The walkThe chips carry the same machinery as the red ones, so the next-empty arrow works in fill mode without a second way of moving.

What it costs

A filler sees one more quiet mark on each rail row, which pushes a long pillar name onto an extra line — the same thing the red count already does today when something is missing.

You lose a door you were not using. With nothing owed on a plan, the way in is the pen, which is where you edit everything else on that page.
