A function’s Overview: the Key Objectives editor gets the page, a Unit column, and an editable Led by

Both pictures are the real platform (the demo’s Merchandising, given one objective shaped like your Consumer Finance screenshot). Nothing in reading mode changes — this is the edit/fill view only.

Today the complaint

The table edits inside the half-width card: the Objective box gets 101px and clips, the Dir. select is 34px so its value never shows, Compile clips to “Late”, there is no Unit column at all, and Led by is a read-only line even with the pen open.

Proposed what you sign off

While the pen or fill mode is open, the objectives take a full-width band under the two cards — exactly what a unit’s Foundation already does when edited.

What changes

  • Room. In edit and fill mode the Key Objectives table leaves the half-width card for a full-width band under it (reading mode stays exactly as it is). Every column becomes readable: Dir. shows its value, Compile shows the whole word.
  • Unit. The table gains the same Unit column the unit’s objectives table has: picked from the fixed list (B EGP · M EGP · EGP · % · # …), riding the target as it already does everywhere else — nothing new is stored. A bare number typed into This year inherits the row’s unit, and a filler can set a missing one, same as on a unit.
  • Wrapping. The Objective name becomes a growing box that wraps — the same treatment the plan’s titles got. Short names stay one line.
  • Led by. With the pen open, the office picks the head from the register on the row itself — it writes the same single fact Setup › Supporting functions’ Head column writes, so the two can never disagree. Anyone who is not the office keeps the read-only line, because the save would refuse them anyway.
Costs, stated: while editing, the “What it is” card stands alone above the band (a short card with space beside it — the same trade the unit’s Foundation made). And the unit-side objectives table keeps its one-line Objective box today; if you want the wrapping there too, say so and both sides move together.
