Presentation on the function's line

Moving a supporting function's Presentation button onto the tab row where a unit's already sits, and giving that page the Bands menu it has never had.

Drawn in the running platform Nothing built yet Awaiting your word

“can you move the presntation button for the functions to be in the same place like what we did in the units while having the bands button as well?” Islam, 4 September

Measured first, and it is narrower than it sounds: this is the only Performance page in the product that draws its Presentation button in the page body. A unit's, the group's, a company's and a pillars-format function's all put it on the tab row with the Bands menu beside it. One page is out of step, and it is the one you are looking at.

What that page does today

A supporting function that plans in capabilities — Finance, here — on its Performance page.

What it would do instead

The same page with the control moved — produced by moving the platform's own button in the live page, so this is that build with one thing in a different place, not a drawing beside it.

The page it would match

A business unit's Performance page, unchanged, for the comparison.

A function that plans in pillars is already drawn by the unit's own page, so it has had this since that routing was built. The two halves of “supporting function” have been disagreeing with each other on this screen.

The change

One line, in one function, calling the thing the other four Performance pages already call.

src/group-render.js · renderFnPerformance()
return '<div class="pageact">' + presentMenu("fn", fk) + '</div>' +
return perfActs(presentMenu("fn", fk)) +

perfActs is what hangs a page's controls on the tab row, and it adds the Bands menu itself — which is why the second half of the ask comes free rather than needing a control of its own.

What it costs, and what it leaves alone

Vertical space
The page gains a row back. The capability band moves from y 300 to y 237, and everything under it with it.
Who sees what
Nothing. The same menu with the same entries, gated by the same rules — Download the plan stays the office's, and reordering stays where it is. The control moves; nobody's rights move.
The other pages
Untouched, and it would be asserted. A unit, the group, a company and a pillars function all already take this path and none of them changes.
The Reporting tab
Untouched — it writes its own controls to that row and is a different renderer.
Narrow windows
To be measured before it ships, not assumed: the tab row would carry two more controls, and a function's tab names are longer than a unit's.

What I need from you

Say yes and I will make the change, measure the tab row down to a small laptop, and add a check that asserts the two pages agree rather than asserting a coordinate — so a later change to both stays green and a change to one does not.

Two things I would rather ask than assume:

  1. Bands on this page as well as Presentation — you asked for it, and it is worth naming that it is genuinely new here, not a restoration.
  2. The group and a company still have no Presentation button at all. That is outside what you asked and I have not touched it — say the word if you want it looked at separately.
