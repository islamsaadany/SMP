The objectives table, while the pen is open

Screenshots of the real platform at 1600px. Nothing in the sources was changed to make this page.

“When I edit the objectives table the table is very tight and crammed. Do you suggest that when I edit the foundation to have the sections over each other, or at least split the table to be below the other sections to take the full page width?”

Why it is crammed

The Foundation is a two-column grid, so the aspiration card gets about 45% of the page — and it is being asked to hold a six-column table with a text field in every cell. That is the whole of it.

The objectives belong inside the aspiration when you are reading: the aspiration says where the unit is going and the objectives say how you would know it got there. It is only authoring that needs the room.

What is proposed, exactly

Only while the pen is open, the objectives block leaves the aspiration card and becomes a full-width band beneath both columns. Reading mode is untouched.

Deliberately not the whole page stacking. “Who we are” and the aspiration statement are short prose and read better side by side; it is only the table that does not fit. Stacking everything would push the table further down the page to solve a problem it does not have.

What it costs

With the table gone from it, the Winning Aspiration card becomes short, so there is empty space beside “Who we are” while editing — visible in the right-hand shots above.

That is the trade: a quiet gap in edit mode, for a table whose every field can be read and used. Reading mode, which is where almost all the time is spent, does not change at all.
