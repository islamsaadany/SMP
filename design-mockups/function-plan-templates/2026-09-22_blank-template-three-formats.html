04Two things that are yours to decide

Decision 1 — does each file carry only its own sheets?

Today one workbook serves both: press Projects and you get the four project sheets and an Actions sheet. That was decided on purpose for the file a named subject downloads, so sheets do not appear and disappear under somebody who switches format.

Recommended Each blank template carries only what its format uses

Projects drops the Actions sheet; Objectives & actions carries Read me, Objectives and Actions and nothing else. Pressing a named button is saying which format you are in, so the file can be honest about it.

Costs: a function that downloads its own plan still gets all seven sheets, so the blank file and the filled one differ in shape for the same function.
Alternative Both buttons make the same file

The third button is a label on a file that already exists — no builder changes at all, and the blank and the filled file match.

Costs: two buttons that produce one identical workbook, and whichever you press you get four sheets you must leave empty.

Decision 2 — does each file's Read me list only the subjects it fits?

The Read me's first question is which subject is this for, answered from a dropdown. Today the projects workbook offers every function that plans in projects or in objectives and actions, plus every capability — eight names on the demo. So the wrong file can still be filled in for the right subject.

Recommended Narrow each list to that format

The objectives template offers only functions that plan that way; the projects template stops offering them. The file then refuses the wrong subject at the cell, where somebody can still act on it.

Costs: a function whose format is changed after a file was downloaded can no longer name itself in that file — it downloads again.
Alternative Leave the list as it is

Nothing about an existing file changes.

Costs: a plan can be authored in the wrong shape and nothing says so — the page simply does not draw what was uploaded.

05Found on the way, and not folded in

Each is a change to something you did not ask about, so it is flagged rather than made.

  • The projects workbook's Read me says “Capability” above the name — true when a function's projects lived inside one, and it now offers seven supporting functions and one capability. The pillars workbook one column left says “Business unit or function”.
  • The button says “Pillars” as a literal, where the Setup control beside it says whatever this client calls a pillar. A tenant that renamed them sees two words for one thing.
  • A capability plans two ways, a function three. Whatever the buttons say, only a function can be objectives-and-actions — so the sentence has to name the subject, not only the format.
