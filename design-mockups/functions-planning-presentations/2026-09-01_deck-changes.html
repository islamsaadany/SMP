What changes

What we are aiming at — the objectives, and nothing else

Pillars functions only

The slide leads with Winning aspiration over an empty space, because a function inherits its aspiration from the unit it plans under and never writes one. Under it, Dir. and By 2027 are columns a function has no values for — its objectives carry a weight and a target for this year. What is left is the objective and what it is aiming at. A business unit's slide is untouched.

No SWOT section

Pillars functions only

Five slides — a cover of zeros and four empty ones — for something a function does not have. Its strengths and threats are the unit's, written on the unit's own deck.

The quarters read as the four boxes

Every deck

The plan, performance and reporting screens all draw a tactic's quarters as four boxes, filled where the work is planned. The slides print Q1, Q2 instead — which arrived when two versions were merged, with no decision behind it. Same marks as the screens, sized for a projector.

Where the unit stands — the third number

Every unit deck

The Performance screen has shown three headline numbers since they were introduced: what the unit is judged on, how the work it set itself is going, and whether that work is landing on time. The slide was left at two, so the middle one — the pillars — is missing from every review deck. Nothing new is worked out; the figure already exists and is already on screen.

Objectives read as a table, and the layout switch goes

Everywhere objectives are read

The objectives block has two layouts behind a small switch — cards, which is what it opens on, and a table. Cards give each objective its own box and put the 3-year figure underneath in small grey type; the table lines the targets up in a column you can run your eye down. Table only, and the switch is removed.

Still open

Answered: a blank weight is never nought

Islam: “if it’s missing it should be considered equally weighted objectives not 0”, and “there is no weighting on the objectives in units, it needs to be added”. Both built. A blank weight now counts as the average of the ones that were set; where none were set every objective counts equally; and a unit’s objectives carry a Weight column of their own.

The other half is not done and is recorded: a figure that arrives by upload against a target holding no usable number is stored and left unscored, silently. Deriving it would move existing scores, so it waits for a separate yes.

Answered: the long figure, and the doubled unit

Both built. A figure written out in full reads at its target’s scale (3.59B EGP), display only, with the whole number on the hover and nothing rounded away — and no figure in the shipped plan moves. Typing a unit into the reporting box no longer adds it a second time.

Fixed, and left alone

Built: the unit written twice — 8 M EGP M EGP

Reproduced, and no decision needed. The reporting box holds the bare number and shows the unit beside it; the unit is added back on save. Type 8 M EGP into an empty box — which is the natural thing to do — and it is added a second time.

Fixed: a unit already there is never added again, however it was spelled. A different unit is left exactly as typed rather than replaced — entering “8 B EGP” against a target in M EGP says something specific, and rewriting it would change a figure a thousandfold in silence. Rows already stored doubled read correctly again the next time the figure is entered; say the word if you want the existing ones cleaned in one pass instead.

The “of plan” column and the progress column

Both stay exactly as they are in this branch. Removing “of plan” from the slides would change no score — that was checked — but it also sits on the screens people report against, which is its own conversation.
