Insights — the library, and the room it is published from

Two screens for sign-off before a line of either is written. Forefront publishes from the client's card; the client searches, opens and downloads, and has no way to write. Drawn in the real pages' own stylesheets — the console frames add three rules and the client's app is the module document the Trial module already established.

Taking it back
Withdraw Leaves the client's library. Its address answers not found, so nobody is told it ever existed. Nothing is lost and it can go back out.
Delete Ends it. The file goes with it. Withdraw first — nobody may delete a report a client is still reading.
Both offDrawn disabled here because this report is a draft: there is nothing to withdraw, and delete needs a withdrawn report. Each says why in its own line rather than leaving a dead control to guess at.
NewTwo rules — the category chip (a tag with a pressed state) and the file strip. The rest is .ecard, .lab, .fld, .wpair, .byline, .apart, .teamrow, .btn.
VersionMoved by replacing the file and by nothing else, so the number means one thing.
Not drawnNo per-item permissions and no scheduled publishing. Both were asked and answered whole module, for now.

What I need your word on

  • The five category names. Analysis · Macro · Market · Sector · Governance. The attached file had a sixth, Other — dropped, because a report filed under Other is a report nobody finds. They are ours to set and the same for every client, so they should be words that fit every client we have.

  • One order and no sort control on the client's screen — newest report first.
  • Download only, no preview.
