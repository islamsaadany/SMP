Internal Tracker: the topic on the row

Same five actions in both versions, drawn with the tracker’s own styles.

  • Where it sits: the topic gets its own column right before the week, so every topic lines up in one place instead of trailing after the action’s name.
  • How it looks: a small rounded tag in normal letters with a gold dot, not gold capitals.
  • No topic: the row shows a quiet “+ Add a topic”. It gets a light outline when you point at the row (shown on the third row). Pressing it opens the same topic list the add line already uses, including “New topic…”.
  • A topic that is set: press the tag to change it or take it off. A double-click on the name now only renames the action.
  • Grouped by topic: the column stays empty, because the group heading already names the topic. This is how it works today too.
  • Cost: the action name loses about 130px of width, so a long name wraps a little sooner.
