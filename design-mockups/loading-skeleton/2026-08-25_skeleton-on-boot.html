Two things arrive late, not one. The colours are the visible half: the tenant’s accent and bar are set on Setup → Branding and live in the database, so the page opens in the file’s colours and swaps when the answer lands.

So does the content. The file has the worked example baked into it. On a client deployment that means a flash of Raya Trade’s units and figures before their own appear — which is worse than a colour shift and is the same fix.

Proposed

while loading

Neutral grey in the shape of the page. No accent, no tenant colour, no content.

Grey is the whole idea. Nothing on this screen has a colour it will have to change — not the bar, not the tabs, not a scoring band. So there is nothing left to shift when the answer lands: the real page simply replaces it, once.

It does not pretend to be a particular page. Until the server says who you are, the platform does not know whether you are opening a unit’s plan or the group’s performance — a rail-and-pane skeleton would be right for one and wrong for the other. A heading and three blocks is true of both.

The blocks fade gently rather than sitting still, because a static grey page reads as broken. It holds still for anyone whose device asks for less motion.

The rules it follows

A loading state that can get stuck is worse than the glitch it replaces.

Only where there is a server

Opened as a file there is nothing to wait for, so the skeleton never appears at all.

Never sticks

If the database cannot be reached, the page paints anyway — the same fallback that runs today, just after the skeleton instead of before it.

A backstop

If the answer has not come in a few seconds, it stops waiting and paints. Nobody is left looking at grey.

No blink

A fast answer would otherwise flash the skeleton on and off. It stays a moment once shown, so it reads as one step rather than a stutter.

What I need a yes on

1 · While the platform waits for the database, it shows this grey skeleton — the bar included — instead of the page in the wrong colours.

2 · The skeleton is shape-neutral: a heading and three blocks, not a copy of any one page.

3 · A soft fade while it waits, still for anyone whose device asks for less motion.
