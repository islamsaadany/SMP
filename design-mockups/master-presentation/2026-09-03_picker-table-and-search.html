03Two smaller calls

Say nothing and I take the recommendation.

1

What the search matches

  • Recommend

    The name and the code. Typing mob finds Mobile and MB finds it too — those are the letters now on the pills at the bottom of the deck, so both halves of the feature answer to the same thing.

  • Either way

    Typing never redraws the dialog, and it filters the left only — so a row dropped in the flow always lands where it looks. A filter that hides rows while you drag among them is how a drop goes somewhere else.

2

Does the number stay

  • Recommend

    Yes. With a grip doing the moving the number is no longer a control — but it is what the deck's own strip says while you present (Retail Stores · 2 of 4), so it is worth its 26px.

04What it costs to build

Almost nothing is new, and one limit is worth knowing before you say yes.

The grip is the platform's own. The same handle the Setup tables and a unit's pillars are dragged by, driving the same reorder machinery — so this adds no new way to move a row, and inherits two things that were already paid for: it is keyboard-operable (focus the grip, press up or down), so dropping your arrows costs nobody their keyboard; and a reorder that does not account for every row exactly once is refused rather than applied, which is a real fault that has bitten this product before.

The one limit, measured: a pointer drag does not auto-scroll. With four or six in the flow that never comes up; with fifteen the list scrolls, and moving a row from the bottom to the top means dragging in two goes. The keyboard path has no such limit, so I would make an arrow-key move scroll the row into view — a line, and it makes the long case workable without adding a control.

And the trap the drawing found: the platform floors every data table at 620px so a plan table never squashes. Inside a 520px column that runs straight out of the dialog, so both of these tables are exempted explicitly.

Everything else is untouched: the list of subjects, what a tick writes, when it saves, the deck it opens, and every server rule.
