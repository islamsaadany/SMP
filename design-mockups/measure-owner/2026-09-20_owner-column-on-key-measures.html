A key measure gets an Owner

So that “Measure owner” can be a row on Roles & access, the same way Tactic owner now is. Every picture below is the real platform, shot twice.

“I believe we need to add measures & tactics owners as roles so I can set their accessability and accordingly Mahdy access can be switched on of orr.”

Why this one needs a picture

The tactic half is built and needed none: a tactic already carries an Owner, so the role simply reads it. A key measure carries none — not one of the 76 in the worked example, and no column on the table in either mode — so a Measure owner row would have nothing to read. The field has to exist first, and a new column on a table is a picture before it is a change.

What is proposed

  • One column, straight after the measure’s name, where a tactic’s Owner already sits on the table below it. Picked from the register, never typed — the same control a tactic’s Owner uses.
  • Optional, and never counted as missing. A measure with nobody named is an ordinary, complete line. Counting it would put the red word on all 76 the day it landed and hold Submit everywhere.
  • Carried by the upload workbook, appended to the Measures sheet — otherwise downloading a plan and uploading it back would quietly drop every owner.
  • Shown wherever a tactic’s Owner is shown: the Plan pane, Performance and the Reporting page.

What this does not do

  • It changes nobody’s access on its own. The Measure owner row would ship at nothing in every column, exactly as Tactic owner does.
  • It does not touch the pillar’s Owner. Pillar owner stays what it is and still reaches the whole pillar when that row is opened.
  • It moves no figure and no score. An owner is a name on a row.
  • Nothing already stored moves, and there is no migration.

What I need from you

One word, and I build it

If the column in the pictures is right, say so and the field and the Measure owner row land together. If you would rather the owner sat somewhere else — under the measure’s name, or only while the pen is open — say which and I will draw that instead before anything is built.
