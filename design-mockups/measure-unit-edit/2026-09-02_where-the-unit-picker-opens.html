What happens when you use it

The unit has never been a field of its own — it lives inside the target (37.5M EGP is one value the column splits for display). So with no number yet, the unit is held on its own until one arrives to join it. This is already how a tactic’s outcome behaves.

The row still owes a target. The count, the red word and Submit’s refusal are all unchanged.
2 · Type the number

3 · Stored
Target  90%
One value, spelt the way the plan has always spelt it. Nothing new is stored and nothing is migrated.

What does not change

Reading mode

Untouched. A target still prints as the whole value it always did, and a row with nothing still says Missing.

Filling gaps

A custodian filling gaps keeps today’s rule: they set a unit where a target exists, and a blank row stays the office’s. Say the word if you want that too.

Every stored figure

No score moves, nothing is migrated, and the workbook, the deck and the archives read exactly as they read now.

The one cost

A target holding only a unit is not a usable target, so it must keep counting as Missing — on the page and on the server. On the demo plan that moves nothing (0 of 274 targets are non‑numeric). On your tenant, a target written as words (TBD, Maintain) would start counting as Missing.
