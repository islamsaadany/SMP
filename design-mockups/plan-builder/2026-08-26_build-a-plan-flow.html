Building a plan on the platform

The SMO team picks a unit or a function — or creates one — chooses how it plans, and is walked through authoring the whole plan on the platform's own pages. No file, no second editor: a guided flow over the pens that already exist.

1What is already settled

Agreed in the alignment before this mockup — the mockup draws these, it does not reopen them.

✓Functions choose, units don't A unit always plans in pillars. Only a function with nothing behind it is asked pillars or projects — the existing format switch, asked at a better moment.
✓Guided mode, not a wizard The flow walks the platform's real pages with the pen open. Every field is the page's own; every server rule applies unchanged.
✓Live immediately The plan appears as it is built, like pen edits today. No draft flag, no state to forget to clear; missing things read honestly as missing.
✓New or existing subject The first step offers the existing units and functions and creating a new one in place — which also gives Setup › Business units its missing "+ Add".

8What this costs, and what it touches

An audit of every empty state comes first

The editors were built for correcting an imported plan, so some first-rows cannot be written — an empty unit's "Who we are" has no way to add its first clause. Part one of the build is walking every authoring surface from a truly empty subject and fixing what cannot start from nothing. The builder is only as good as these.

Setup › Business units gains "+ Add a unit"

Name, code prefix, company, weight — the same shape functions already have. The builder's "+ New business unit" and this button are one function, never two. A new unit starts unweighted and the weighting page says so.

Almost nothing new on the server

Every edit the builder makes is a plan edit the server already classifies (unitPlan / capPlan); creating a unit or function is setup, which is already the SMO's. No new stored state — the band's progress is derived from the plan itself.

Deliberately not in this module

Units planning in projects (settled: functions only). Draft visibility (settled: live immediately). Templates or pre-filled example plans. Changing anything about how the xlsx import works — the two doors stay siblings.
