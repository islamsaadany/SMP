What stays

  • The navy row in the brand colour, with the unit's name in it (Mobile, underlined in gold).
  • The grey tab row (Reporting in its orange box) and the squared section switch, as built this round.
  • The top part above is a picture of the real platform, not a redrawing.
  • Every letter below it uses the platform's own typeface and its own sizes and weights, read off the running page: 19px for the pillar name, 13px for table text, 10.5px capitals for column heads, the code face for codes and numbers. No new font is brought in.

What changes

  • The pillars list keeps the cards under each other, all the same height, with soft corners like the rest of the page.
  • The lines button in the list's heading stays: pressed, each card shows its kind (Capability or Direction) and its counts; not pressed, just the code and the name.
  • The pillar's code and name sit on one line at the top, with the kind as a tag on the right. The owner line is gone.
  • Key measures and tactics become two blocks in one card, with the count beside each heading and the grey lines under the headings removed.
  • The table cells get a light grid, and the numbers line up.
