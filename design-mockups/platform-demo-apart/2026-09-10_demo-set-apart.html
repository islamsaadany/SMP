What it costs, and what it does not

Nothing about the demo itself moves. It stays a tenant of its own at /demo, seeded by the same switch, opened by the same card, with the same amber and the same Demo tag. What changes is where the card is drawn.

The search box stops reaching it. It says Search clients, so that is the honest behaviour — and it is a change: today typing “demo” finds it.

Below about 520px the page is one column either way, and the demo simply follows the clients, which is what it does today.
