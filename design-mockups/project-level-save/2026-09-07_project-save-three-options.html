First: what Mark done does today

It is a signal, not a save and not a lock. Pressing it writes one small mark against that project and puts the word Done on its band, so whoever submits the whole function can see which projects are finished. That is all it does.

Does it save?
No — but nothing is lost. Every number is already sent the moment you leave the box.
Does it freeze anything?
No — the boxes stay open. You can keep typing after pressing it.
Does it tell the office?
Yes — the bar reads Your 2 projects · 1 of 2 done, and the band reads Done.

So the gap is small. Against the capability's Save draft, what is missing is (1) a press that pushes it there and then and says whether it landed, and (2) a freeze.
