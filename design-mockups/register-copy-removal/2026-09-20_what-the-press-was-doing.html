At rest, nothing changes. The register with the control and without it are the same picture, byte for byte — the value was always styled to look like a value rather than like a button. So there is no new look to agree; what changes is only what the cell does.

4 · And selecting the text starts working

The original reason for making it a button was that you could not select text in this table. The button is what made that true.
