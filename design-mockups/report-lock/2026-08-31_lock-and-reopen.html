Design review · 31 August 2026

Locking a finished report

Submit and Save draft both close the report. Reopen unlocks it. Screenshots are the real page with the proposed bar injected.

“The submit or the save as a draft locks the report and in both cases you can find the button Reopen to unlock it.”

Today

NowNothing is ever locked. Submitting changes the wording and leaves every box editable.
Measured, not assumed After pressing Submit, all 12 figure boxes and the note were still fully editable — so a report can be changed after you have received it.

Proposed

NewSave draft — parked. Dimmed and read-only. Reopen carries on.
NewSubmitted — sent. The same lock; the word and its colour are what differ.

How it behaves

  • The figures, notes and the owner’s note all go read-only — still readable, so the report can be reviewed while closed.
  • Reopen unlocks it in both states, and the bar returns to Submit and Save draft.
  • Reopening after a submission withdraws it, exactly as Reopen my report does today.
  • Cancel becomes Close — it only leaves the report; it has never discarded anything, so the old word promised a threat it does not carry out.
  • Two words, two colours: Draft saved quiet, Submitted green. Same control beneath both.
One thing to confirm Save draft becoming a lock means it is no longer “save and keep typing” — every draft save now ends the sitting, and carrying on is one press of Reopen.
