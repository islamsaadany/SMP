Three things worth saying before you decide

A PowerPoint is shapes, not a picture

The reason this file exists rather than the PDF is that you can edit it in the room. So the gauges and pills on screen cannot come across as themselves — they would have to become images, and an image is not editable. Everything above is text, tables and rectangles: alignment, colour, italics, weight, the card, the mark. That is the whole of what a .pptx will honestly carry, and it is enough to make it read like the deck.

The footer mark is the one thing with a real cost

Every other change is text and geometry, inside the file that already builds these slides. The unit's mark is a picture, so the package needs a media part and a link from each slide — plumbing the download has never had. It is drawn above as a dashed box so you can see what it costs. If you would rather not spend it, say so and the footer becomes the unit's name in small grey type instead.

Nothing about the deck on screen changes

This is the converter that turns the deck you present into a file. The deck itself, the PDF, the plan download and every figure in the platform stay exactly as they are — and I will prove that rather than promise it, by reading every figure before and after.

What I need from you: a yes to this shape, or a note on any slide above. Then I build it against the sources and check it — including running the current build to watch the check fail first, so the green run means something.
