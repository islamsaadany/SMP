3The columns

  • The top — the group's and a division's own pages.
  • This box: Plan and This box: Reporting — the unit, function or capability the person belongs to. Plan and reporting stay two separate answers.
  • Other boxes — every unit, function and capability they don't belong to.
  • Reporting cycle and Setup — as today.

Today the table asks the same question twice — once for units, once for functions. On the demo the two answers never differ for anybody, so they become one.

4Nothing moves — and the one case where it would

On the demo, every person opens and does exactly what they do today. Checked cell by cell: 0 of 117 change.

If a client set two of today's cells differently that now become one cell — for example a project owner who can see a function's plan but not a unit's — the change stops for that client and names the cell, so you decide. Nothing is merged by guessing.

5A pillar can name a Custodian

Today only a company's direction has a Custodian seat. Every pillar gets the same seat, beside its Owner, in the plan's Edit.

6The rules that stay outside the table

44 rules are not table cells today (for example: only the Super user edits Roles & access; a part owner never submits the report). Each is reviewed one by one while building — it becomes a cell or stays a named rule with its reason. None changes what anybody can do.
