A2 · the measure's number only Recommended

The key measures table already numbers its rows, so the tactic points at the number: one line, however long the names are. Hover a number (or tap it) and the full name shows. The count on the measure (above) uses the tactic numbers the same way, so the two tables point at each other in one language. The pillar can carry a small legend of its measures, folded by default.

A3 · number and the start of the name, one per line, clipped

A middle way: each measure on its own short line, the number first, the name cut with an ellipsis at the cell's width. Readable without hovering, but a tactic with three measures still takes three extra lines, and a cut name can mislead when two measures start with the same words.

What to decide

  • A2 is the one that stays tidy whatever the names are: one line per tactic, numbers both ways, the full name on hover and in the legend. A1 is what you feared. A3 is readable but tall.
  • The number is the row's place in the table, so if a measure is moved up or down its number moves with it everywhere, the same moment. Nothing is typed, so nothing goes stale.
  • Legend or not: the folded list of the pillar's measures under the tactics table (shown open above) can stay, or hover alone can do.
  • The red line "No tactic supports it yet" is shown; say if a measure with no tactic should stay quiet instead.
