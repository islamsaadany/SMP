What to decide

  • Which look: A (line under the tactic, count on the measure), B (a column), or C (the grid). A and C can also go together: the line on the tactic, and the grid as a fold-out under the pillar.
  • Which measures are offered: the mockup offers only the pillar's own key measures. Any key measure in the unit's plan is possible, but the line then has to say which pillar the measure belongs to.
  • Missing or not: here a tactic with no key measure simply has no Supports line. It could count as missing instead, with the red word and the Next-gap walk, like a missing owner.
  • Where else it shows: the same line on the Performance page and the deck's tactics slide, and a Key measures column on the Tactics sheet in Excel (by name, so the upload and download carry it). The mockup shows the Plan page only.
