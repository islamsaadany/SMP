Where the Note Goes

On a unit’s Performance page, the plan’s description and the reporter’s note sit in the same cell, in the same grey, at the same size — so a permanent statement and a this-cycle statement read as one paragraph. Two ways to tell them apart, drawn out of the running platform with your own two tactics in the rows.

Option 1 — the note is named where it sits

Recommended Costs no width

The note keeps its place and stops reading as a second description.

A hairline rule down its left edge separates it from the description without costing a line, and one uppercase key — Reported, in the micro size the product already uses for column keys — says which of the two it is. The rule is --line, not the accent: this page already spends its gold on Report and the scoring colours.

  • WidthUnchanged. The table fits its pane at 1920, 1600, 1440 and 1280 — exactly the widths it fits today.
  • HeightRow 1 grows 121 → 143px at 1600; row 2 shrinks 140 → 143px. The two rows become the same height.
  • ReachesA unit’s Performance page. The deck already separates the two and does not change.
  • CostOne word added to the row, and below 1100px the indent makes the existing overflow worse (see the table).

Option 3 — the note takes its own column

Breaks the fit at 1280px

What the projector already does, brought onto the page.

The note leaves the name and becomes a tenth column, matching the review deck, which has given it a Note column since it was built. One fact, described the same way on the page and on the slide.

The cost is that the note is a paragraph and a paragraph needs width, so it takes that width from the only other flexible column — the one holding the tactic’s name and description.

  • WidthOverflow starts at 1280px, where the table fits today. An ordinary laptop.
  • Tactic columnLoses 581px at 1920 and 358px at 1600. The name wraps to three lines; the description becomes a narrow ribbon.
  • Agrees withThe review deck, which already gives the note a column of its own.
  • Against§158 — the rule is fit, never “and it scrolls”. This is a tenth column on a table that has nine.
