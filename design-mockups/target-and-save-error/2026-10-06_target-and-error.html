2. The red "Not saved" bar says what went wrong

Today the bar gives no reason at all, and the hover on "Not saved." only says "HTTP 400". The server's actual reason is thrown away. The proposal keeps the first line as it is and adds a second, smaller line with the details we need, plus a Copy details button so the person can paste it to us.

What the details line carries:

  • The reason in words, as the server gave it, for example "Capability key objectives: a row has no id."
  • The error number, the date and time, and a reference (for example SMP-7F3K2Q). The same reference is written into the server's log, so I can find the exact failure from it.
  • For a server error (500), the reason names the field or table that failed, never the raw database message.
The wording in the shots is an example. The 400 and 500 reasons shown are made up to show the shape. The real one is whatever the server says at that moment.
