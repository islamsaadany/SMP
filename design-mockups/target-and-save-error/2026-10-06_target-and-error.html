Proposed

The bar stays one line. It gains one link at the end, Copy error for the Strategy Office, which copies the details for pasting to us. The same details are also:

  • written to the browser console as an error, so anyone with the console open sees it straight away,
  • on the hover of "Not saved.", and
  • written to the server's log under the same reference (for example SMP-7F3K2Q), so I can find the exact failure.

The details are: the server's reason in words (for example "Capability key objectives: a row has no id"), the error number, the date and time, and the reference.
