One thing to confirm. You asked for the target to dim. I have also dimmed the direction (≥ / ≤) and the compile rule (Sum / Latest / Average) on a Y/N row, because neither means anything once there is no number — a live control that changes nothing is worse than one that is not there. Say the word if you want only the target dimmed and those two left live.

Yes scores 100, No scores 0, and a row nobody has answered is not scored at all — it stays out of the average and still owes a figure, exactly like an empty number box does today.

What it does to the counts

Three consequences worth saying out loud before it is built.

It is not Missing A Y/N target has no number on purpose, so it counts as a complete answer. Without this every Y/N row would show a red Missing for ever and block Submit.
It counts in the average 100 or 0 lands in the pillar's and the unit's figures like any other row, which is what you chose.
Nothing already written moves The unit lives on the target itself, so no plan, figure or archive changes. Y/N only exists on rows somebody picks it for.
