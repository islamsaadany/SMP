And what stays

  • Start: a month list and a year list. Both must be picked before Add.
  • End: the same two lists, with Still running first in the month list. Picking it greys out the year.
  • An end before the start is still refused in words, as today.
  • Nothing stored changes: it is still saved as a month and a year, so assignments already added are untouched.
  • Same on Edit, with the assignment's own months already picked.
