2 · Next time they open the platform on that computer

Kept changes are sent by themselves. If they land, the person is told and the report to the office closes itself. If somebody else changed the same number meanwhile, they choose.

3 · What the office sees

One list under Setup › Running the cycle, sorted by line, holding only what never landed. Each row is one changed line, never a copy of the plan, so there are no versions to compare. Two people sending the same line is flagged on that row.

  • Apply uses the sender's own permissions, exactly like their save would have.
  • A row leaves the list when it is applied, discarded, or goes through by itself.
